# AI File Organizer

AI File Organizer 是一个完全本地运行的 Windows/Linux/macOS 桌面文件整理工具。它先使用用户规则和可修改的扩展名规则分类，只有无法判断的文件才会调用 OpenAI-compatible API。所有移动操作均先生成预览，绝不覆盖同名文件，并记录在 SQLite 中以便撤销。

## V1 功能

- PySide6 三栏桌面界面：目录树、可排序/筛选/多选的文件表格、图片或文本预览与详情。
- 主菜单与设置页支持简体中文、English、日本語、한국어即时切换；文件名、路径、分类和其他用户数据不会被翻译。
- 默认使用原生 Windows 黑白系统控件风格，另提供深色、海洋和暖色材质；可从界面安全导入、删除或生成 `.aifopack` 示例包。材质包只允许达到最低可读对比度的受控颜色和一张背景图，不执行 QSS 或脚本。
- 递归或单层扫描；默认跳过隐藏/系统文件以及应用自身目录。
- 规则优先级固定为：手动规则 > 前缀规则 > 扩展名规则 > AI > 待确认。
- 可新增、修改、删除、启停、排序和测试规则；所有内置扩展名规则均可编辑。
- 主窗口提供醒目的“API 配置…”入口和配置状态；内置 OpenAI、DeepSeek、Kimi、阿里云百炼、硅基流动、智谱 GLM 厂商预设，也可使用任意 OpenAI-compatible 服务。Base URL、API Key、模型、超时、并发数、Temperature 与 Token 费率全部在界面管理。
- OpenAI-compatible `/chat/completions` 与 `/models` 连接测试；服务不支持模型列表时自动回退到最小聊天请求。普通文件按总字符预算动态分批（每批最多 8 个），图片视觉请求单独处理。
- AI 严格 JSON 校验，错误响应、超时、限流和断网只影响对应批次，不会终止任务；停止分析或关闭窗口会主动关闭在途连接并中断重试等待。
- 文本采用有限读取，PDF 只读取前三页且坏文件不会中断批次；图片视觉默认关闭，启用后只发送去除 EXIF/GPS 的有限尺寸 JPEG 缩略图。
- 分类置信度颜色提示、手动改分类、用户习惯规则建议（至少 3 次，必须确认才创建）。
- 重命名是独立可选功能，默认关闭；只有单独勾选后才按模板改名。非法文件名会清理，且永不静默覆盖。
- SQLite 逐文件事务日志、逐条可取消的整理/撤销预览、启动时安全归一未完成记录；撤销前校验路径边界和文件内容身份。
- GUI 与文件日志、API Token 统计（服务不返回 usage 时显示未知）。
- 后台扫描、AI、解压和整理；可安全请求停止，单文件失败不终止整个任务。

## 自动解压

支持 `.zip`、`.7z`、`.rar`、`.tar`、`.tar.gz` 和 `.tgz`。解压是独立预处理阶段，成功后的文件会重新进入扫描和分类流程。

- 默认不自动解压，并保留原压缩包。
- 一旦开启自动解压，会固定递归查找所选目录的全部子目录；此发现流程不受普通文件“递归扫描”开关影响。
- 支持原目录同名文件夹、统一目录和临时目录三种模式。
- 支持 0–5 层递归解压，默认 3 层。
- 先尝试无密码，再按用户密码库优先级尝试，不进行任何暴力破解。
- 密码优先存入系统 Credential Manager/Keychain；磁盘上的 `data/passwords.json` 只含备注和编号，不含密码。安全凭据后端不可用时密码仅在当前进程内保存。
- 在写入前和写入过程中同时检查文件数量、声明/实际解压大小、压缩比、任务总容量和实时磁盘空间。
- 每个归档成员均执行路径与名称校验，拦截绝对路径、`..`、盘符/ADS、Windows 设备名、尾点空格、链接、特殊文件和规范化重名。
- 目标目录和文件始终自动生成不重名名称。
- 统一解压目录会拒绝磁盘根目录、系统目录和应用自身数据目录；崩溃遗留的内部暂存文件也永远不会重新进入扫描。扫描时会绑定压缩包所在根目录和内容身份，解压及原包后处理前重新验证整条父目录链，拒绝扫描后发生的目录链接重定向或文件替换。
- 可选择成功后保留原包、移动到“已解压压缩包”或放入系统回收站；从不永久删除。

ZIP/TAR 使用 Python 标准库，7z 使用已修复安全问题的 `py7zr >= 1.1.3`。RAR 使用 `rarfile`，并且只接受安装在 Windows `Program Files` 下的绝对 7-Zip 路径，绝不从当前目录或 `PATH` 启动解压程序；没有可信后端时会明确显示“格式不支持”。

## 安装与启动

要求 Python 3.11+。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Windows 也可以直接双击 `start.bat`。首次使用可直接点击主窗口顶部的“API 配置…”，也可以完全不配置 API，仅使用规则分类。没有 API Key 时扫描、规则分类、预览、整理、解压与撤销都能正常工作。

### 构建 Windows EXE

```powershell
.\build_exe.ps1
```

构建产物位于 `dist\AI File Organizer.exe`。它是无控制台窗口的单文件启动器，首次启动会稍慢，并使用单实例锁避免重复打开。打包版始终在 `%LOCALAPPDATA%\AI File Organizer\` 保存规则、设置、操作历史和日志，不在 EXE 同级写入用户数据。

## 基本流程

1. 选择目录并点击“扫描”。
2. 如果启用自动解压，所选目录及全部子目录中的归档都会安全解压，产物自动加入当前任务。
3. 前缀和扩展名规则立即分类；“待确认”文件可运行 AI 分析或双击分类单元格手动修改。
4. 默认只移动分类；如需改名，单独打开“重命名选项”设置模板并勾选“启用重命名（可选）”。
5. 点击“执行整理”，在最终预览中逐条保留或取消。
6. 需要恢复时点击“撤销上次操作”，再次确认预览。

压缩文件右键菜单提供立即解压、指定密码、更换密码、跳过和打开解压目录。

完整的界面操作、四语切换、材质包格式和安全说明见 [USAGE.md](USAGE.md)。主窗口“帮助 → 使用说明”也内置了四语快速指南。

## 数据与隐私

- 打包版数据根目录：`%LOCALAPPDATA%\AI File Organizer\`；源码运行时使用项目内的 `data/` 与 `logs/`。
- `data/organizer.db`：规则、设置、逐文件操作历史、手动分类记录、API 用量。
- `data/passwords.json`：密码条目的非敏感元数据；不包含密码。
- `logs/app.log`：滚动文件日志。实际解压密码永远不会写入日志或界面。
- API Key 不写入 SQLite 或源码，按规范化 API 服务源隔离并优先保存在系统安全凭据中；系统无安全后端时仅保留到当前运行结束。
- 只有用户主动点击 AI 分析后才会联网。是否发送文本、完整目录和图片可分别控制；非本机 HTTP API 会被拒绝。
